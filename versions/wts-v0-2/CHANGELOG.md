# WTS 0.2 changelog

## 浏览器操作分散延迟实验

- 基于 0.1，给 Skill 显式编排的点击、输入、按键、内容读取加入轻微浮动等待；导航后先安全检测再等待。验证码检测、加载轮询和取消响应保持及时。
- 每份详情的三个常规操作合计仍为 15 秒，每段约 4–6 秒，每个候选人独立分配。普通操作以原 action_delay_ms 为基准浮动 ±20%，替代原点击固定尾延迟。
- 搜索、前置检查、探测及条件性页面恢复有少量额外等待。搜索、筛选、评分和详情预算保持不变。
- 随机值在编译时固化，同一工作流可追溯；包身份为 wts-v0-2 / 0.2，用户 Skill 根目录在运行时解析。
- 本版取代未发布的固定 15 秒等待草案，0.1 保持不变，0.3 保留占位。
- **BLOCKED_RUNTIME**：验证码明确恢复与已完成结果保留的运行器门槛尚未通过；未安装、未进行真实猎聘效果测试。见 references/detail-pacing-experiment.md 和仓库 docs/wts-v0-2-validation.md。
