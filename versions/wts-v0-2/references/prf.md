# PRF：先试后晋升

步骤 12 读。PRF 是产生**待试词**的唯一来源；反思和救援都只使用已有的词。

## 支持词状态

每个支持词处于以下状态之一：

- **活跃词**：可进主路径。
- **备用词**：救援时激活。
- **待试词**：只能进下一轮第二路，以 PRF 探针执行。
- **已拒绝**：终止使用。
- **无法判定**：终止使用，并终止本次寻访。

已拒绝与无法判定是终态，与"可重试的失败"无关。

## 提议（每轮最多 1 个）

前提全部成立才提议：本轮已完成评分；没有现存待试词；未触发致命错误或未对账状态；已完成轮数 < 最大轮次（第 3 轮不再提议，因为没有下一轮可试）。

- **种子**：榜单中符合、总分 ≥ 75、必须满足 ≥ 70、风险不适用或 ≤ 45 的候选人，按总分取前 5；不足 2 名则本轮不提议。
- **负样本**：本轮已评分中不符合或总分 < 60 的候选人。
- **候选短语**：在至少 2 份种子详情原文中逐字出现的技术、工具、框架、方法短语（"Flink CDC""LangGraph"），最多提出 4 个。以下一律拒绝：已在关键词或已用词族中的；职责句、公司名、地点、学校、学历、薪资；只含标题的词、泛词；只出现在概括性总结而非经历原文的词；负样本中出现比例 ≥ 0.4 的。
- 接受第一个通过的短语，标为待试词，记下它引用的种子原文。

## 试用与裁决

待试词只在下一轮第二路以 PRF 探针执行（SKILL.md 步骤 7）。执行后先按运行结果对账，再裁决：

| 对账结果 | 裁决 |
| --- | --- |
| 结果明确：该路带来 ≥ 1 名新增可推荐候选人，且没有明显噪音或方向漂移 | 晋升为活跃词，可进后续主路径 |
| 结果明确：未达上一行标准 | 已拒绝 |
| 证明未执行或未产生效果 | 保持待试，下一轮重新编译执行后再试 |
| 效果未知 | 保持待试，暂停等待对账，不提议新词 |
| 已确认执行但结果确定性不可评价（详情全部失败、评分致命失败） | 无法判定，终止本次寻访并保存证据 |
